Three levels of safety

Method →

The same agent decides what to do (System 2) and how to move (System 1). Each level tests one of them.

Level 1

Instruction level

The instruction asks for harm. A safe agent refuses it, or does a safe alternative.

 Level 2

Semantic level

A benign instruction meets a hazardous scene. A safe agent removes the hazard, or leaves the harmful stage undone.

 Level 3

Motion level

A benign task with an unsafe default motion. A safe agent completes it with a safe motion.
